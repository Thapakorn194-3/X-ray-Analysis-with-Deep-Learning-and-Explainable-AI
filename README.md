## 1. บทนำ (Introduction)
Online X-ray Analysis with Deep Learning and Explainable AI เป็นระบบสนับสนุนการวินิจฉัยวัณโรค (TB) จากภาพเอกซเรย์ทรวงอกผ่านเว็บเบราว์เซอร์ โดยใช้โมเดลการเรียนรู้ของเครื่อง 3 รูปแบบ และวิธีการอธิบายผล 2 รูปแบบ เพื่อให้ผู้ใช้เข้าใจเหตุผลเบื้องหลังการทำนายของ AI

### 1.1 โมเดลที่รองรับ
* **CNN (DenseNet121):** โครงข่ายประสาทเทียมแบบลึกที่ทำนายผลโดยตรง
* **SVM:** ใช้ CNN สกัดคุณลักษณะของภาพแล้วจำแนกด้วย Support Vector Machine
* **XGBoost:** ใช้ CNN สกัดคุณลักษณะและจำแนกด้วย XGBoost ซึ่งให้ผลรวดเร็ว

### 1.2 วิธีการอธิบายผล (XAI)
* **Grad-CAM:** แสดงพื้นที่สำคัญบนภาพเอกซเรย์ที่ส่งผลต่อการตัดสินใจของ CNN 
* **LIME:** อธิบายผลได้กับทุกโมเดลโดยการจำลองการเปลี่ยนแปลงพื้นที่ย่อยของภาพ

## 2. การติดตั้งและตั้งค่า (Installation)

### 2.1 ความต้องการของระบบ
* Python 3.9 ขึ้นไป
* ไฟล์โมเดล: `exp2_best.keras`, `svm1_best.pkl`, `xgb1_best.json`

### 2.2 การติดตั้ง Library
```bash
pip install flask flask-cors tensorflow scikit-image scikit-learn joblib xgboost matplotlib pillow opencv-python
```

### 2.3 จัดเตรียมโครงสร้างไฟล์และโฟลเดอร์

นำไฟล์ทั้งหมดไปไว้ในโฟลเดอร์โปรเจกต์เดียวกัน โดยจัดโครงสร้างดังนี้:

project_folder/ \n
├── static/ \n
│   └── index.html          # หน้าเว็บหลัก \n
├── app.py                  # โปรแกรม \n
├── exp2_best.keras         # โมเดล CNN \n
├── svm1_best.pkl           # โมเดล SVM \n
├── xgb1_best.json          # โมเดล XGBoost \n


app.py: วางไว้ที่โฟลเดอร์หลัก 

index.html: ต้องนำไปใส่ไว้ในโฟลเดอร์ย่อยชื่อ static/

เตรียมไฟล์โมเดลทั้ง 3 ไฟล์ไว้ในเครื่อง (สามารถวางไว้ที่โฟลเดอร์ใดก็ได้)

### 2.4 ตั้งค่า Path ของโมเดลใน app.py
เปิดไฟล์ app.py ด้วย Text Editor และค้นหาส่วน MODEL_PATHS (จะอยู่ช่วงต้นไฟล์) จากนั้นแก้ไข Path ของไฟล์โมเดลให้ตรงกับตำแหน่งที่บันทึกไว้ในเครื่อง:

Python
MODEL_PATHS = { \n
    'cnn': r'D:\DEMO\exp2_best.keras', \n
    'svm': r'D:\DEMO\svm1_best.pkl', \n
    'xgb': r'D:\DEMO\xgb1_best.json', \n
} \n
ข้อแนะนำ: หากใช้ Windows แนะนำให้ใส่ r ไว้หน้า String (ตามตัวอย่าง) หรือใช้เครื่องหมาย / แทน \ เพื่อป้องกัน Error จาก Path \n

### 2.5 รันเซิร์ฟเวอร์
เมื่อตั้งค่าเสร็จแล้ว ให้รันเซิร์ฟเวอร์ด้วยคำสั่ง:

```bash
python app.py
```
จากนั้นเปิดเว็บเบราว์เซอร์และเข้าไปที่ http://localhost:5000 เพื่อเริ่มใช้งาน
